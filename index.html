EVERYTHING YOU NEED

Six powerful modules, one plugin. No fluff, no fragmentation.

Player Management

  • Browse every online player and click to manage
  • Invsee — view and edit any player's inventory
  • Kick, Ban, Warn with typed durations and reasons
  • Trust levels 1–5, each unlocking more permissions

Parkour & Checkpoints

  • Placeable checkpoint plates (4 types)
  • Falls below limit? Teleport back to latest checkpoint
  • Auto-granted "Return to Spawn" item
  • Give-up mechanic built in

Kits & Templates

  • Full kit editor: armor, offhand, 27 slots + hotbar
  • Apply kit to all eligible players in one click
  • Import from inventory, clear editor, clear all kits
  • 16 shulker color templates — nameable, loadable, deletable

Custom Weapons

  • Kinetic Arrow Shooter — fires a 20-arrow volley
  • Strips armor on hit
  • One-use bow, carefully balanced for SMP play

Server Controls

  • PVP toggle — ops and trusted always bypass
  • Wither Sound — ambient growl with adjustable range
  • Death Messages — fake "died/left" broadcasts
  • Difficulty / Time / Weather with auto-revert

Automatic Systems

  • Join handling — untrusted players cleared & teleported to spawn
  • Spawn protection — block breaking near spawn
  • 3 warnings = 30-second spectator penalty
  • Dynamic MOTD with live player count gradient

COMMANDS

Everything ops need, nothing they don't.

/noonblade
Opens the main control menu
/noonblade help
Lists every Noonblade command in chat
/noonblade activate <key>
Activate your license key
/noonblade trust <player> <1-5>
Set a player's trust level (ops)
/noonblade untrust <player>
Remove a player's trust (ops)
/noonblade skin set <nick> <player>
Set a player's skin + persistent tab nickname (ops)
/noonblade reload
Reload all configs, kits, templates, warnings, checkpoints (ops)
/warn <player> <reason>
Warn a player (ops + trusted)

LICENSE SYSTEM

Keys are managed through Discord — fast, secure, and instant.

Get a key

Apply in the Discord server — keys are generated automatically via the Noonblade bot.

1 key = 1 server

The first server to activate a key owns it permanently. Sharing it with another server returns "invalid".

Instant revocation

Rotate or ban a key from Discord and the plugin disables within seconds.

Auto checks every 5s

The plugin re-validates in the background on every server. Bans take effect almost instantly.

READY TO RUN NOONBLADE?

Download the plugin, drop the .jar into your plugins/ folder, restart, and activate your license key.
